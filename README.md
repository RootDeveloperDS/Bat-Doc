## 🛑 The Problem: The Windows Battery Report Crisis

Windows ships with a powerful native diagnostic command (`powercfg /batteryreport`). However, the output it generates creates severe real-world problems for laptop owners, students, enterprise IT departments, and hardware buyers:

* 🔴 **Cryptic Wall of Data (No Actionable Health Score):**  
  Windows generates an overwhelming 1,500+ line HTML dump filled with raw milliwatt-hours ($\text{mWh}$) and ISO timestamps. It never answers the most critical question: *"Is my battery in good health, degrading normally, or dangerously deteriorated?"*
* 🔴 **The Silent "Vampire Drain" Nightmare (Modern Standby / S0 Sleep Leaks):**  
  Windows laptops frequently boil inside backpacks and lose 20% to 50% battery overnight while supposedly "asleep." Windows buries sleep drain records across hundreds of disjointed state-change rows, making it virtually impossible for everyday users to calculate hourly leak rates ($\%/\text{hr}$).
* 🔴 **The Hyphen Mystery (`-` Cycle Counts):**  
  Leading OEMs (Dell, HP, Lenovo, ASUS) frequently leave hardware cycle counts reported as `-` through ACPI. Users mistakenly assume their battery sensors are broken or untracked.
* 🔴 **Invisible Lost Runtime:**  
  Windows never calculates how many actual hours and minutes of portable unplugged battery life have vanished compared to factory specifications.
* 🔴 **Used Laptop Marketplace Trust Deficit:**  
  When buying or selling second-hand laptops on eBay, Reddit, or Craigslist, buyers have no standardized, tamper-evident health certificate to verify battery honesty.

## ⚡ Usage & Quickstart (Fastest to Advanced)

BATDOC is built with a zero-friction philosophy: **zero complex setup, zero Python, zero Node.js, and zero registry bloat.**

Choose the method that fits your workflow, ordered strictly from the **fastest, zero-footprint instant command** to permanent system installation and developer builds:

```
Fastest (3 sec) ──► Instant 1-Line PowerShell  (No download, in-memory, auto-cleanup)
                    Web App / Drag & Drop       (Any device, zero install, PWA)
                    Portable .exe               (1-click, silent background execution)
                    Winget Package Manager      (Permanent CLI command)
                    Portable Batch Script       (USB toolkits & air-gapped systems)
Slowest / Dev   ──► Build from Source           (Custom mods & compiler scripts)
```

---

### Tier 1: Instant 1-Line PowerShell (Fastest — 3 Seconds, Zero Clutter)
> **Best for:** Anyone who wants an immediate diagnosis right now without downloading files, installing software, or cluttering their system.

Open Windows PowerShell (press <kbd>Win</kbd> + <kbd>X</kbd> $\rightarrow$ choose **Terminal** or **PowerShell**), paste the command below, and press <kbd>Enter</kbd>:

```powershell
irm https://raw.githubusercontent.com/RootDeveloperDS/Bat-Doc/master/batdoc.ps1 | iex
```

*✨ What happens automatically:*
1. Windows queries your battery hardware via native `powercfg` in your temporary directory.
2. The BATDOC diagnostic engine bundles your telemetry into an interactive, self-contained report (`BatDoc-Report.html`) directly on your **Desktop**.
3. Your default browser launches immediately with your diagnostic dashboard.
4. All intermediate working files are purged automatically. **100% clean, temporary, and non-invasive.**

---

### Tier 2: Instant Web App & Drag-and-Drop (Zero Install, Any Device)
> **Best for:** Users who already have a `battery-report.html` file, or want to inspect reports from a Mac, Linux, tablet, or phone.

1. Navigate to the hosted mirror: **[rootdeveloperds.github.io/Bat-Doc](https://rootdeveloperds.github.io/Bat-Doc/)**
2. Drag and drop your `battery-report.html` into the dropzone.
3. *(Optional)* Click **"Install App"** in your browser's address bar to install BATDOC as a standalone **Progressive Web App (PWA)** in your Windows Start Menu.
4. **100% Client-Side:** Processes your report locally inside your browser engine. Works completely offline—even in Airplane Mode.

---

### Tier 3: Standalone Portable Executable (`batdoc.exe`) (1-Click Native App)
> **Best for:** Users who prefer a permanent desktop icon with zero terminal interaction.

1. Download **[`batdoc.exe`](https://github.com/RootDeveloperDS/Bat-Doc/releases/latest)** from the latest release.
2. **Double-click `batdoc.exe`**.
3. **Completely Silent Execution:** Runs with zero black console windows flashing. It queries hardware registers, compiles `BatDoc-Report.html` on your Desktop, and opens it in your browser within 2 seconds.

---

### Tier 4: Microsoft Windows Package Manager (`winget`) (Permanent CLI)
> **Best for:** Developers, system administrators, and power users who want a global command line tool.

Install via official Microsoft Winget:

```cmd
winget install RootDeveloperDS.BatDoc
```

Once installed, invoke BATDOC from anywhere in your terminal or the Windows Run dialog (<kbd>Win</kbd> + <kbd>R</kbd>):

```cmd
batdoc
```

---

### Tier 5: Portable Batch Script (`batdoc.bat`) (USB Toolkits & Air-Gapped PCs)
> **Best for:** IT repair shops, field technicians, and air-gapped corporate computers without internet access.

1. Download or copy **[`batdoc.bat`](batdoc.bat)** and **[`batdoc-standalone.html`](batdoc-standalone.html)** onto a USB flash drive.
2. Insert into the target laptop and **double-click `batdoc.bat`**.
3. Generates the executive diagnostic locally without requiring an active internet connection.

---

### Tier 6: Build & Compile from Source (Advanced / Developer)
> **Best for:** Contributors customizing analytics, chart renderers, or compiling custom Windows binaries.

Clone the repository and inspect the modular source:

```bash
git clone https://github.com/RootDeveloperDS/Bat-Doc.git
cd Bat-Doc
```

Run validation tests, bundle the standalone HTML engine, and compile the native Windows C# binary:

```powershell
# Validate syntax and module integrity
node .\tools\test-bundle.js

# Compile standalone single-file HTML distribution
node .\tools\build-standalone.js

# Compile native Windows PE executable (uses native csc.exe, zero external compiler needed)
powershell -ExecutionPolicy Bypass -File .\tools\build-exe.ps1

# Validate Winget manifest schema compliance
powershell -ExecutionPolicy Bypass -File .\tools\test-winget.ps1
```

## 🔒 Privacy & Security Architecture

BATDOC was engineered from the ground up for zero data exfiltration:

* 🛡️ **100% Client-Side Processing:** All parsing, statistical analysis, and SVG generation execute locally in your browser memory.
* 🛡️ **Zero Network Calls:** No telemetry, no Google Analytics, no tracking pixels, and no remote API dependencies.
* 🛡️ **Air-Gap Compatible:** Disconnect your internet connection or switch to Airplane Mode—BATDOC works with 100% functionality.
* 🛡️ **Zero Registry Infiltration:** The 1-line PowerShell launcher runs in-memory and leaves no persistent background services or scheduled tasks.
